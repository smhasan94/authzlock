## Approach

`diff.py` becomes the single comparison engine. `compute(base, current) -> Diff` matches
routes by `(path, view)`; a `RouteChange` carries the old and new `Route` and a list of
`FieldChange(field, old, new)` where nested mappings (`django_auth`, `object_scoping`) are
flattened to dotted names such as `django_auth.permission_required` and
`object_scoping.get_queryset.overridden`. Custom permission registry differences are
reported separately as `custom_added`, `custom_removed` and `custom_changed` (docstring or
`used_by` changes) and never mark a route as changed by themselves. Every list is sorted by
route key or dotted path. `Diff.is_empty` covers all six lists. `render_check` is updated
for the flattened names.

Rejected: matching routes by path only (a view move would look like a permission change;
the key includes the view so it shows as remove plus add, which is honest); deep-diff
libraries (one function is enough and keeps output deterministic).
