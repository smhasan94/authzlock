Implementation plan

Ticket: SHA-182 Lint, format and type tooling. Written 2026-09-29. Assumes the AC amendments
proposed alongside this plan (AC6 and T5 move to SHA-183, T2 and T4 reworded) are approved.
Builds on the SHA-181 plan.

## Approach

All configuration lives in `pyproject.toml`. ruff replaces flake8, isort and black with one
tool: rule sets E, W, F, I, UP, B, SIM, line length 100, target py310, `authzlock` as
first-party for import sorting. mypy runs in strict mode on `src/authzlock` only, with
`ignore_missing_imports` overrides for `django.*` and `rest_framework.*` because the package
imports them dynamically and their stubs are heavy. `noxfile.py` gets `lint` and `typecheck`
sessions; `nox.options.sessions` is set to those two and SHA-183 appends `tests`.
`.pre-commit-config.yaml` uses the official ruff hooks pinned to the same ruff version as the
dev extra.

Rejected: django-stubs and djangorestframework-stubs (add later if the extractor code gets
hard to type without them); running mypy strict on `tests/` (fixture projects would need
stubs; revisit after Epic 2); pyright (brief says mypy).

## Changes

- `pyproject.toml`: `[tool.ruff]`, `[tool.ruff.lint]`, `[tool.ruff.lint.isort]`,
  `[tool.ruff.format]`, `[tool.mypy]` (`strict = true`, `files = ["src/authzlock"]`,
  `warn_unused_ignores = true`, `python_version = "3.10"`), overrides table.
- `noxfile.py`: `lint` (installs ruff only; runs `ruff check .` and `ruff format --check .`)
  and `typecheck` (installs `-e .[dev]`; runs `mypy`). `nox.options.sessions`.
- `.pre-commit-config.yaml`: ruff check with `--fix` and ruff format hooks.
- `src/authzlock/py.typed`: empty marker.
- `tests/test_tooling.py`: subprocess-based checks below. Helper `run_tool(args, cwd)`.

## Test mapping

- T1 -> not a pytest test: `nox -s lint typecheck` run locally on the PR, automated by
  SHA-184's CI job.
- T2 -> `tests/test_tooling.py::test_ruff_reports_unused_import` (writes `import os` to a
  temp file, runs `ruff check --config pyproject.toml`; expects exit 1 and `F401`).
- T3 -> `tests/test_tooling.py::test_mypy_strict_rejects_untyped_function` (expects
  `no-untyped-def` in output).
- T4 -> `tests/test_tooling.py::test_precommit_blocks_unformatted_file` (marked `slow`;
  `git clone` the repo into `tmp_path`, add a badly formatted file, run
  `pre-commit run --all-files`; expects non-zero and the file reformatted).
- T5 -> moved to SHA-183 as its T7.
- T6 -> `tests/test_tooling.py::test_mypy_reports_unused_type_ignore`.
- Extra: `tests/test_tooling.py::test_precommit_ruff_rev_matches_dev_extra` (the pinned hook
  version equals the ruff version in the dev extra, so the two cannot drift).

## Sequence

1. ruff config; run `ruff format .` and `ruff check --fix .`; commit the reformat.
2. mypy config and `py.typed`; `mypy src/authzlock` green on the SHA-181 code.
3. `noxfile.py` with both sessions; `nox` green.
4. `.pre-commit-config.yaml`; `pre-commit run --all-files` green.
5. `tests/test_tooling.py` with T2, T3, T6, extra, then T4. `pytest` green.

## Risks and unknowns

- First `pre-commit run` needs network to build hook environments. The offline constraint
  applies to the package, not to developer tooling, but CI caching for it belongs to SHA-184.
- Typer's decorators under mypy strict are fine in current versions; if not, the fix is
  `typer>=0.12` in SHA-181's dependency pin.
- T4 clones the repo, so it needs `git` and takes a few seconds; it is marked `slow`.

## Out of scope

`tests` session and matrix (SHA-183); CI (SHA-184); the hook shipped to target repos
(SHA-233); mypy on tests. No follow-up tickets needed.
