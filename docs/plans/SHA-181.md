Implementation plan

Ticket: SHA-181 Package skeleton and CLI entry point. Written 2026-09-29. Assumes the AC
amendments proposed alongside this plan (AC1, AC5, T1) are approved.

## Approach

A `src/` layout package built with hatchling, with the version single-sourced from
`src/authzlock/__init__.py` and read by hatch's `version.path` setting. The Typer app lives
in `cli.py` and uses an explicit root callback with `invoke_without_command=True`: when no
subcommand is given it prints help and exits 0, and `--version` is an eager option. This
keeps AC3's exit code under our control instead of depending on Click's `no_args_is_help`
behaviour, which changed to exit 2 in Click 8.2.

Rejected: `hatch-vcs` for versions from git tags (SHA-185 needs a literal `__version__` to
compare with the tag); setuptools (brief says hatchling); argparse (brief says Typer).

## Changes

- `pyproject.toml`: build-system hatchling; project metadata (name, dynamic version,
  `requires-python >=3.10`, MIT, classifiers, `typer>=0.12`, `pyyaml>=6`); `dev` extra with
  pytest, ruff, mypy, nox, build, pre-commit, types-PyYAML, django, djangorestframework;
  `[project.scripts] authzlock = "authzlock.cli:app"`; wheel target
  `packages = ["src/authzlock"]`; sdist excludes `tests/`; minimal
  `[tool.pytest.ini_options] testpaths = ["tests"]` (SHA-183 extends it).
- `src/authzlock/__init__.py`: `__version__ = "0.0.1.dev0"`.
- `src/authzlock/cli.py`: `app: typer.Typer`, `_version_callback(value: bool) -> None`,
  root callback `main(ctx, version)`. No other commands.
- `LICENSE` (MIT, copyright line naming the author), `README.md` skeleton, `.gitignore`.
- `tests/test_cli.py`, `tests/test_package.py`.

## Test mapping

- T1 -> `tests/test_package.py::test_wheel_installs_in_fresh_venv` (marked `slow`; uses the

- T3 -> `tests/test_cli.py::test_no_args_prints_help_and_exits_zero`.
- T4 -> `tests/test_package.py::test_wheel_contents` (session fixture `built_wheel` runs
  `python -m build --wheel --outdir tmp`; asserts via `zipfile`).
- T5 -> `tests/test_package.py::test_license_and_readme`.
- T6 -> `tests/test_cli.py::test_unknown_command_exits_nonzero`.
- Extra: `tests/test_cli.py::test_metadata_version_matches_dunder_version` (importlib.metadata
  agrees with `__version__`, proving the hatch version path is right).

## Sequence

1. Write `pyproject.toml`, package files, LICENSE, README, `.gitignore`. Run
   `pip install -e ".[dev]"` and `authzlock --version` by hand.
2. Add T2, T3, T6, T5 and the extra test. `pytest` green.
3. Add the `built_wheel` fixture and T4, then T1. `pytest` green, then `python -m build`
   from a clean tree to confirm the sdist excludes tests.

## Risks and unknowns

- Click 8.2 changed no-args exit codes. Mitigated by the explicit callback; T3 catches it.
- Hatch `version.path` misconfiguration shows up only at build time. Step 1 runs a build.
- CI does not exist until SHA-184, so "pass in CI" is met retroactively on SHA-184's first
  run. Until then the PR shows a local `pytest` run.

## Out of scope

ruff, mypy, `py.typed` and pre-commit (SHA-182); nox sessions (SHA-182, SHA-183); any
command beyond `--version`. No follow-up tickets needed.
