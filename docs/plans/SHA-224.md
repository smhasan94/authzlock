Implementation plan

Ticket: SHA-224 Lockfile schema v1, serializer and loader. Written 2026-09-30. Builds on
SHA-200's model. See `docs/plans/README.md` for field order and the route key.

## Approach

`lockfile.py` holds `SCHEMA_VERSION = 1`, `dump(inventory) -> str` and `load(text) ->
Inventory`. `dump` builds plain dicts in the fixed field order from the shared design note,
sorts every order-free list (`methods`, class lists, `permission_required`, `used_by`,
`unknown_decorators`), sorts routes by `(path, view)` and custom permissions by dotted path,
then writes with `yaml.safe_dump(sort_keys=False, default_flow_style=False,
allow_unicode=True, width=4096)` so nothing wraps, no anchors appear and a trailing newline
is present. `load` parses with `yaml.safe_load` and runs a small hand-written validator
that checks `schema_version` first (unknown or newer gives "schema_version 2 is newer than
the supported version 1; upgrade authzlock"), then required keys and types per route,
reporting the offending path such as `routes[0].permission_classes`. Both directions go
through `Inventory.to_dict`/`from_dict`, so `check` compares parsed objects, not text.

Rejected: JSON (less readable for reviewers); a YAML library with round-trip comments
(`ruamel`, extra dependency and not needed since the file is generated); pydantic for
validation (heavy for six checks).

## Test mapping

- T1 -> `test_t1_dump_starts_with_schema_version_and_sorted_routes`.
- T2 -> `test_t2_round_trip_equality` (hand-built inventory covering null, `dynamic`, a
  composed expression, nested dicts).
- T3 -> `test_t3_newer_schema_version_is_rejected`.
- T4 -> `test_t4_missing_routes_key_is_named`.
- T5 -> `test_t5_unsorted_lists_are_sorted_on_dump`.
- T6 -> `test_t6_docs_example_loads_and_documents_every_key`.
- T7 -> `test_t7_wrong_field_type_names_the_path`.
- Extra: `test_extra_dump_is_idempotent` (`dump(load(dump(x))) == dump(x)`).

## Sequence

1. `dump` with T1, T5; `load` with T2, T3, T4, T7; extra.
2. `docs/lockfile.md` and T6.

## Risks and unknowns

- PyYAML quotes strings that look like numbers or booleans (`"4.2"`, `"yes"`); the
  round-trip test covers such values so quoting stays consistent.
- Very long regex paths are single YAML scalars thanks to the large `width`.

## Out of scope

The CLI (SHA-225); cross-machine determinism tests (SHA-227); migrations.
