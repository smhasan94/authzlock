Implementation plan

Ticket: SHA-272 Matrix cell for minimum DRF 3.14 on Django 4.2. Written 2026-09-30. Assumes
the amendment proposed alongside this plan is approved: the cell is a separate nox session
`tests_min_drf` rather than a twelfth entry in `SUPPORTED`, so the eleven `tests(...)`
session names and the SHA-183 tests stay unchanged.

## Approach

Add one session, `tests_min_drf`, to `noxfile.py`: Python 3.12, `django~=4.2.0`,
`djangorestframework==3.14.*`, exporting `AUTHZLOCK_DJANGO=4.2` and `AUTHZLOCK_DRF=3.14`,
running the same `pytest`. Add it to `nox.options.sessions` and as a job in `ci.yml`, so it
runs everywhere the matrix runs. A new smoke test asserts the installed DRF version against
`AUTHZLOCK_DRF` when set, and asserts DRF 3.16 or newer when unset inside any other nox
session (`AUTHZLOCK_DJANGO` set, `AUTHZLOCK_DRF` unset).

Rejected: a third parametrize dimension on `tests` (renames all eleven sessions and every
place that mentions them); DRF 3.15 cells (neither bound; add only on a reported bug).

## Changes

- `noxfile.py`: `DRF_MIN = "djangorestframework==3.14.*"`, session `tests_min_drf`,
  `nox.options.sessions` gains it.
- `.github/workflows/ci.yml`: job `tests_min_drf` (same steps as a matrix cell, Python 3.12).
- `tests/test_smoke.py`: `test_t2_drf_version_matches_session` and the `>= 3.16` branch.
- `tests/test_nox_matrix.py`: `test_t1_exactly_one_min_drf_session` and
  `test_t4_min_drf_never_pairs_with_django_5`.
- `tests/test_ci_workflow.py`: expected sessions list becomes
  `["lint", "typecheck", "tests", "tests_min_drf"]` (SHA-184 T4 updated to the new truth).
- `DEVELOPMENT.md`: mention the session.

## Test mapping

- T1 -> `tests/test_nox_matrix.py::test_t1_exactly_one_min_drf_session` (session exists,
  is the only one installing DRF 3.14, and is Python 3.12 with Django 4.2, read from the
  noxfile constants).
- T2 -> `tests/test_smoke.py::test_t2_drf_version_matches_session` (in the 3.14 cell).
- T3 -> same test, `>= 3.16` branch, in every other cell; skipped outside nox.
- T4 -> `tests/test_nox_matrix.py::test_t4_min_drf_never_pairs_with_django_5`.
- Extra: `tests/test_ci_workflow.py::test_extra_ci_has_min_drf_job`.

## Sequence

1. noxfile session; run it locally; smoke test.
2. CI job; SHA-184 T4 expectation updated; `nox` green (14 sessions).
3. PR; confirm the new job appears green in CI.

## Risks and unknowns

- DRF 3.14 with Django 4.2 on Python 3.12: DRF 3.14.0 predates 3.12 but works; if the cell
  fails on an import, fall back to Python 3.11 for this session and amend AC1.
- Extraction code written later must avoid DRF 3.15+ only APIs; this cell is what catches it.

## Out of scope

Any change to the eleven `tests(...)` cells. No follow-up tickets needed.
