## Approach

`gitutil.py` wraps two subprocess calls: `git rev-parse --show-toplevel` (raising
`GitError`, exit 2, "not a git repository") and `git show <ref>:<repo-relative lockfile>`,
which returns `None` when the path does not exist at the ref and raises `GitError` with
git's stderr for an unknown ref. `diff` loads the base inventory from that text (or an empty
inventory plus the note "base ref has no authz.lock"), extracts the current one, runs
`compute` and `classify_diff`, and renders. `render.py` gains `render_text` (grouped by
label, one line per route with label, methods, path, view and the field change) and
`render_markdown` (summary line "1 loosened, 0 tightened, 0 added, 0 removed, 0
changed-unknown", a table for loosened and tightened, a collapsed `<details>` for added,
removed and changed-unknown, and a hidden marker `<!-- authzlock -->` for the action to
find its own comment). Exit codes: 0 empty diff, 1 any change, 2 error; `--fail-on
loosened` makes the exit 1 only when a loosened change exists.

Rejected: reading the base lockfile from the working tree (stale); comparing two lockfiles
(the PR's own lockfile may be stale, which is the case the tool exists to catch).
